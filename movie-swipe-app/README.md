# Feeelmback - Movie Swipe App

Mobile application prototype developed during the Apple Foundation Program.

## Overview

This project was developed as part of the Apple Foundation Program and focused on creating an engaging mobile experience to help users discover movies through a swipe-based interaction system inspired by modern recommendation platforms.

The application was designed following Human-Centered Design principles, combining usability, accessibility and intuitive interaction patterns.

## Features

* Swipe-based movie selection
* User-centered design approach
* Interactive recommendation experience
* Mobile-first interface
* Rapid prototyping and testing

## Apple Foundation Program

The project was developed within the Apple Foundation Program, an educational initiative focused on innovation, app development, creativity and problem solving using the Apple ecosystem.

The experience included design thinking activities, prototyping, teamwork and the development of digital solutions addressing real user needs.
