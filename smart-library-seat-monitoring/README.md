# Smart Library Seat Monitoring

Real-time IoT system for monitoring library seat occupancy.

## Features
- STM32 Nucleo-F401RE
- VL53L0X distance sensor
- Bluetooth communication
- Firebase Realtime Database
- Real-time web dashboard

## Architecture

STM32 → Bluetooth → Node.js Bridge → Firebase → Web Dashboard
