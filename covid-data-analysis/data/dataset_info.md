# Dataset Information

The dataset used in this project contains COVID-19 provincial and regional data released by the Italian Civil Protection Department.

Data include:

- Date
- Region code
- Region name
- Province code
- Province name
- Province abbreviation
- Latitude and longitude
- Total confirmed cases
- Additional notes

The original dataset was collected from official public sources and imported into an Oracle relational database for normalization, analysis and reporting purposes.

Period covered:

25 February 2020 – 3 May 2020

Source:

https://github.com/pcm-dpc/COVID-19
